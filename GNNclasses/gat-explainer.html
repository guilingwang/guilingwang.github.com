01 / CORE IDEA

一句话理解 GAT

GAT 的核心：对于图中每个节点， 根据邻居节点的特征重要性（注意力权重） 来加权聚合邻居信息，从而生成该节点的新表示。
GCN 的问题

所有邻居一视同仁，权重由度矩阵固定决定，无法区分邻居的重要性。

GAT 的改进

通过可学习的注意力机制，为每个邻居动态分配权重，重要邻居贡献更大。

02 / MATHEMATICS

数学推导：一步一步拆解

1

线性变换：将特征映射到高维空间

每个节点的特征向量先乘一个可学习的权重矩阵 W，进行维度变换。

h'i = W · hi
W ∈ RF'×F — 权重矩阵  |  hi ∈ RF — 节点 i 的输入特征  |  h'i ∈ RF' — 变换后的特征
2

计算注意力系数（未归一化）

将节点 i 和邻居 j 的变换特征拼接，乘注意力向量 a，再通过 LeakyReLU 得到原始注意力值。

eij = LeakyReLU( aT · [ Whi || Whj ] )
eij — 节点 j 对 i 的重要性  |  a ∈ R2F' — 注意力向量  |  || 表示向量拼接
3

Masked Softmax：只对邻居归一化

关键！softmax 的分母只包含节点 i 的邻居（包括自身），不是全图所有节点。这就是 masked 的含义。

αij = exp(eij) / Σk ∈ N(i) exp(eik)
N(i) — 节点 i 的邻居集合（包含 i 自身） |  αij ∈ [0, 1] — 归一化后的注意力权重
4

加权聚合：生成新节点表示

用注意力权重 α 对邻居的变换特征加权求和，得到节点 i 的新特征。

h'i = σ( Σj ∈ N(i) αij · W · hj )
σ — 非线性激活函数（如 ELU） |  输出维度 F'，与输入维度 F 可以不同
5

多头注意力：K 个独立注意力并行

使用 K 组独立的 (W, a) 参数并行计算，结果拼接或取平均，增强表达能力和稳定性。

h'i = ||k=1K σ( Σj ∈ N(i) αij(k) · W(k) · hj )
拼接输出维度 = K × F'  |  最后一层通常用平均代替拼接

import torch
import torch.nn as nn
import torch.nn.functional as F
from torch_geometric.nn import MessagePassing
from torch_geometric.utils import add_self_loops, softmax

class GATConv(MessagePassing):
    """
    图注意力网络层 (Graph Attention Network Layer)

    论文: Graph Attention Networks (Veličković et al., ICLR 2018)

    核心思想: 对每条边 (i,j) 学习一个注意力权重 α_ij，
    表示邻居 j 对中心节点 i 的重要性。
    """

    def __init__(self, in_channels, out_channels, heads=1,
                 concat=True, dropout=0.0, negative_slope=0.2):
        """
        Args:
            in_channels:  输入特征维度 F
            out_channels: 输出特征维度 F'（每个头的输出维度）
            heads:        注意力头数 K
            concat:       True=拼接多头结果, False=取平均
            dropout:      注意力权重的 dropout 概率
            negative_slope: LeakyReLU 的负斜率
        """
        super().__init__(aggr='add', node_dim=0)

        self.in_channels = in_channels
        self.out_channels = out_channels
        self.heads = heads
        self.concat = concat
        self.dropout = dropout
        self.negative_slope = negative_slope

        # ===== 可学习参数 =====
        # W: 每个头独立一个权重矩阵 [heads, out_channels, in_channels]
        #   将输入特征 F 维映射到 F' 维
        self.weight = nn.Parameter(
            torch.Tensor(heads, out_channels, in_channels)
        )

        # a: 注意力向量 [heads, 2 * out_channels]
        #   拼接 Wh_i 和 Wh_j 后，用 a 计算注意力分数
        #   2 * out_channels 是因为拼接了两个 F' 维向量
        self.att = nn.Parameter(
            torch.Tensor(heads, 2 * out_channels)
        )

        # 偏置项 [heads, out_channels] 或 [out_channels]
        if concat:
            self.bias = nn.Parameter(torch.Tensor(heads * out_channels))
        else:
            self.bias = nn.Parameter(torch.Tensor(out_channels))

        self.reset_parameters()

    def reset_parameters(self):
        """Xavier 初始化，保证梯度稳定传播"""
        nn.init.xavier_uniform_(self.weight)
        nn.init.xavier_uniform_(self.att)
        nn.init.zeros_(self.bias)

    def forward(self, x, edge_index):
        """
        前向传播

        Args:
            x: [N, F] 节点特征矩阵，N=节点数，F=输入维度
            edge_index: [2, E] 边索引，COO 格式
                        edge_index[0] = 源节点 (j)
                        edge_index[1] = 目标节点 (i)
                        注意：消息从 j 传播到 i

        Returns:
            out: [N, K*F'] 或 [N, F'] 输出特征
        """
        # ---------- Step 1: 线性变换 Wh ----------
        # x: [N, F] -> [K, N, F] 复制 K 份，每个头独立计算
        x = x.unsqueeze(0).repeat(self.heads, 1, 1)  # [K, N, F]

        # 批量矩阵乘法: [K, N, F] @ [K, F, F'].T = [K, N, F']
        # 每个头有自己的 W，得到 K 组变换后的特征
        x = torch.einsum('knf,kof->kno', x, self.weight)  # [K, N, F']

        # ---------- Step 2: 计算注意力系数 ----------
        # 先给图添加自环边 (i,i)，因为节点自身信息也必须参与聚合
        edge_index, _ = add_self_loops(edge_index, num_nodes=x.size(1))

        # 传播消息：在每条边上计算注意力分数
        # message() 定义了每条边上的计算
        # aggregate() 定义了聚合方式（已在 __init__ 中设为 'add'）
        # update() 定义了聚合后的处理
        out = self.propagate(edge_index, x=x)  # [K, N, F']

        # ---------- Step 5: 多头合并 ----------
        if self.concat:
            # 拼接: [K, N, F'] -> [N, K*F']
            out = out.permute(1, 0, 2).reshape(-1, self.heads * self.out_channels)
        else:
            # 平均: [K, N, F'] -> [N, F']
            out = out.mean(dim=0)

        # 加偏置
        out = out + self.bias

        return out

    def message(self, x_i, x_j, edge_index_i, size_i):
        """
        定义每条边 (j->i) 上的消息计算

        这是 GAT 的核心！在这里计算注意力权重 α_ij。

        Args:
            x_i: [K, E, F'] 目标节点 i 的特征（每条边的终点）
            x_j: [K, E, F'] 源节点 j 的特征（每条边的起点）
            edge_index_i: [E] 目标节点索引，用于 softmax 分组
            size_i: 目标节点数量，用于 softmax
        """
        # --- Step 2a: 拼接 [Wh_i || Wh_j] ---
        # x_i 和 x_j 的形状都是 [K, E, F']
        # 在最后一维拼接 -> [K, E, 2*F']
        x_cat = torch.cat([x_i, x_j], dim=-1)  # [K, E, 2*F']

        # --- Step 2b: 计算 e_ij = LeakyReLU(a^T · [Wh_i || Wh_j]) ---
        # att: [K, 2*F']，需要扩展为 [K, E, 2*F']
        # einsum 'keo,ko->ke' = 对最后一维做内积
        alpha = torch.einsum('keo,ko->ke', x_cat, self.att)  # [K, E]
        alpha = F.leaky_relu(alpha, self.negative_slope)     # [K, E]

        # --- Step 3: Masked Softmax ---
        # 关键！softmax 按目标节点 i 分组，只对 i 的邻居归一化
        # edge_index_i 告诉每条边的目标节点是谁
        # size_i 是目标节点的总数
        alpha = softmax(alpha, edge_index_i, num_nodes=size_i)  # [K, E]

        # Dropout 正则化
        alpha = F.dropout(alpha, p=self.dropout, training=self.training)

        # --- Step 4: 加权消息 = α * Wh_j ---
        # x_j 是源节点特征，用 alpha 加权
        # alpha: [K, E] 需要扩展为 [K, E, 1] 来做广播乘法
        return x_j * alpha.unsqueeze(-1)  # [K, E, F']

    def update(self, aggr_out):
        """
        聚合完成后，应用非线性激活

        aggr_out: [K, N, F'] 已经聚合好的结果（Σ α_ij * Wh_j）
        """
        # ELU 激活函数: x if x>0 else α(exp(x)-1)
        return F.elu(aggr_out)

import torch
import torch.nn as nn
import torch.nn.functional as F
import dgl
import dgl.function as fn
from dgl.nn import GATConv

class GAT(nn.Module):
    """
    使用 DGL 官方实现的 GAT
    DGL 将消息传递封装在底层，代码更简洁
    """
    def __init__(self, in_feats, hidden_feats, num_classes, num_heads):
        super().__init__()

        # 第一层: 输入 -> 隐藏层
        # num_heads: 注意力头数
        # feat_drop: 特征 dropout
        # attn_drop: 注意力权重 dropout
        # activation: 输出激活函数
        self.layer1 = GATConv(
            in_feats=in_feats,
            out_feats=hidden_feats,
            num_heads=num_heads,
            feat_drop=0.1,
            attn_drop=0.1,
            activation=F.elu
        )

        # 第二层: 隐藏层 -> 输出层
        # 最后一层通常用 1 个头，并取平均
        self.layer2 = GATConv(
            in_feats=hidden_feats * num_heads,  # 第一层拼接了多头
            out_feats=num_classes,
            num_heads=1,       # 输出层单头
            feat_drop=0.1,
            attn_drop=0.1,
            activation=None    # 输出层不加激活，留给损失函数
        )

    def forward(self, g, features):
        """
        Args:
            g: DGLGraph 对象，包含图结构
            features: [N, F] 节点特征

        Returns:
            logits: [N, num_classes] 分类 logits
        """
        # Layer 1
        h = self.layer1(g, features)     # [N, K, F']
        h = h.flatten(1)                  # [N, K*F'] 拼接多头

        # Layer 2
        logits = self.layer2(g, h)       # [N, 1, num_classes]
        logits = logits.mean(1)           # [N, num_classes] 取平均

        return logits


# ========== 手动实现（理解 DGL 内部原理）==========
class GATLayerManual(nn.Module):
    """
    用 DGL 的消息传递 API 手动实现 GAT
    帮助理解 DGL 的底层机制
    """

    def __init__(self, in_dim, out_dim):
        super().__init__()
        self.fc = nn.Linear(in_dim, out_dim, bias=False)
        self.attn_fc = nn.Linear(2 * out_dim, 1, bias=False)

    def edge_attention(self, edges):
        """
        在每条边上计算注意力分数
        edges.src['z'] = Wh_j  源节点特征
        edges.dst['z'] = Wh_i  目标节点特征
        """
        # 拼接 [Wh_i || Wh_j]
        z2 = torch.cat([edges.src['z'], edges.dst['z']], dim=1)

        # a^T · [Wh_i || Wh_j]，得到标量注意力分数
        a = self.attn_fc(z2)

        return {'e': F.leaky_relu(a)}

    def message_func(self, edges):
        """传递消息：包含源节点特征和注意力分数"""
        return {'z': edges.src['z'], 'e': edges.data['e']}

    def reduce_func(self, nodes):
        """
        聚合：对目标节点的所有入边做 softmax 后加权求和
        """
        # 对所有入边的注意力分数做 softmax
        alpha = F.softmax(nodes.mailbox['e'], dim=1)

        # 加权求和: Σ α * h
        h = torch.sum(alpha * nodes.mailbox['z'], dim=1)

        return {'h': h}

    def forward(self, g, features):
        # 1. 线性变换
        z = self.fc(features)

        # 2. 将特征存到节点上
        g.ndata['z'] = z

        # 3. 在边上计算注意力
        g.apply_edges(self.edge_attention)

        # 4. 消息传递 + 聚合
        # pull 操作：对每个节点，从其邻居收集消息
        g.update_all(self.message_func, self.reduce_func)

        # 5. 返回更新后的节点特征
        return g.ndata.pop('h')

import torch
import torch.nn as nn
import torch.nn.functional as F

class PureGATLayer(nn.Module):
    """
    纯 PyTorch 实现 GAT（不依赖 PyG/DGL）
    用邻接矩阵实现，最直观理解矩阵运算过程
    """

    def __init__(self, in_features, out_features, dropout=0.0, alpha=0.2):
        super().__init__()
        self.in_features = in_features
        self.out_features = out_features
        self.dropout = dropout

        # 可学习参数
        self.W = nn.Parameter(torch.zeros(size=(in_features, out_features)))
        self.a = nn.Parameter(torch.zeros(size=(2 * out_features, 1)))

        self.reset_parameters()

    def reset_parameters(self):
        nn.init.xavier_uniform_(self.W.data, gain=1.414)
        nn.init.xavier_uniform_(self.a.data, gain=1.414)

    def forward(self, x, adj):
        """
        最直观的前向传播：全部用矩阵运算

        Args:
            x:   [N, F]    节点特征矩阵
            adj: [N, N]    邻接矩阵（包含自环）
                           adj[i,j]=1 表示 j 是 i 的邻居

        Returns:
            h': [N, F']   输出特征
        """
        N = x.size(0)  # 节点数

        # ===== Step 1: 线性变换 =====
        # x: [N, F] @ W: [F, F'] = Wh: [N, F']
        Wh = torch.mm(x, self.W)  # [N, F']

        # ===== Step 2: 计算注意力矩阵 =====
        # e_ij = a^T · [Wh_i || Wh_j]
        #
        # 技巧：不拼接，分别计算两部分：
        # a = [a_1, a_2] 其中 a_1, a_2 ∈ R^{F'}
        # e_ij = a_1^T Wh_i + a_2^T Wh_j

        # 先算 a^T Wh -> [N, 1]
        a_input = torch.matmul(Wh, self.a[:self.out_features])  # [N, 1]
        a_input_neighbor = torch.matmul(Wh, self.a[self.out_features:])  # [N, 1]

        # 广播: e_ij = a_input[i] + a_input_neighbor[j]
        # [N, 1] + [1, N] = [N, N]
        e = a_input + a_input_neighbor.t()  # [N, N]
        e = F.leaky_relu(e, negative_slope=0.2)

        # ===== Step 3: Masked Softmax =====
        # 关键！用邻接矩阵 mask：只对邻居做 softmax
        # adj = 0 的位置设为 -inf，softmax 后变为 0
        mask = -9e15 * torch.ones_like(e)
        masked_e = torch.where(adj > 0, e, mask)  # 邻居=e, 非邻居=-inf

        # 按行 softmax（每行对应一个节点，对其邻居归一化）
        attention = F.softmax(masked_e, dim=1)  # [N, N]
        attention = F.dropout(attention, p=self.dropout, training=self.training)

        # ===== Step 4: 加权聚合 =====
        # h' = attention @ Wh
        # [N, N] @ [N, F'] = [N, F']
        h_prime = torch.matmul(attention, Wh)

        # 非线性激活
        return F.elu(h_prime), attention  # 返回结果 + 注意力权重（用于可视化）

常见问题

为什么需要添加自环边 (self-loop)？
如果不添加自环，节点 i 的聚合结果将完全不包含自身的信息。添加自环边 (i,i) 确保节点自身的特征也参与聚合，这是图神经网络中的标准做法。在 GAT 中，节点 i 对自身的注意力权重 α_ii 也会被学习，通常会比较高。
Masked Softmax 和普通的 Softmax 有什么区别？
普通 Softmax 对所有元素归一化（分母是所有元素之和）。Masked Softmax 只对邻居归一化：非邻居位置设为 -inf，使得 softmax 后非邻居权重为 0。这保证了每个节点只聚合其邻居的信息，符合图的局部性假设。
多头注意力 (Multi-head) 的作用是什么？
类似于 Transformer，多头注意力让模型从多个"视角"学习注意力模式。不同头可能关注不同的特征维度或邻居关系。中间层通常拼接多头结果，最后一层取平均以稳定输出。实验证明多头可以提升模型性能并减少方差。
GAT 的参数量是多少？
单头 GAT 的参数量为：F × F' + 2 × F'。其中 F×F' 是权重矩阵 W 的参数，2×F' 是注意力向量 a 的参数。K 头注意力的参数量是单头的 K 倍（假设输出维度不变）。相比 GCN，GAT 多了注意力向量 a 的参数量，但总量仍然很小。

参考论文: Veličković et al. "Graph Attention Networks", ICLR 2018
