01 / CORE IDEA

一句话理解核心概念

Hodge 拉普拉斯的核心：它将图上的拉普拉斯算子推广到高维单纯复形，通过边界算子捕捉k 维洞的拓扑信息，其零特征值的重数就是 Betti 数。
0 阶 L₀

标准图拉普拉斯。L₀ = B₁B₁ᵀ。零特征值个数 = 连通分量数 β₀。

1 阶 L₁

边拉普拉斯。L₁ = B₁ᵀB₁ + B₂B₂ᵀ。零特征值个数 = 一维洞数 β₁（环）。

2 阶 L₂

面拉普拉斯。L₂ = B₂ᵀB₂。零特征值个数 = 二维洞数 β₂（空腔）。

03 / BOUNDARY OPERATORS

边界算子与关联矩阵

1

边界算子 ∂k：从 k-单形到 (k-1)-单形

边界算子描述一个高维单形的"边界"由哪些低维单形组成。定向至关重要：边的方向决定符号，三角形的定向（顺时针/逆时针）决定各边的符号。

∂₁：边的边界
∂₁[vᵢ, vⱼ] = [vⱼ] − [vᵢ]
有向边 [i→j] 的边界是终点 j 减起点 i。这对应 B₁ 矩阵中 +1 和 −1。
∂₂：三角形的边界
∂₂[i,j,k] = [j,k] − [i,k] + [i,j]
定向三角形的三条边按定向循环取正负。若边方向与循环方向一致则为正。

关联矩阵 B₁（顶点 × 边）

B₁[v,e] = +1 如果顶点 v 是有向边 e 的终点；−1 如果是起点；0 如果不关联。

关联矩阵 B₂（边 × 三角形）

B₂[e,t] = +1 如果边 e 的方向与三角形 t 的定向一致；−1 如果相反；0 如果不属于三角形。

06 / HODGE DECOMPOSITION

Hodge 分解：边上的三种流

Ck = im(BkT) ⊕ im(Bk+1) ⊕ ker(Lk)
梯度流 Gradient
im(B₁ᵀ) — 来自顶点势函数

可表示为顶点值的差分。例如：电势差驱动的电流。无旋（curl-free）。

旋度流 Curl
im(B₂) — 来自三角形面

沿每个三角形的循环流动。例如：涡旋流。无散（divergence-free）。

调和流 Harmonic
ker(L₁) — L₁ 的零空间

既无散也无旋的流。对应拓扑洞中的"环绕流"。维数 = β₁。

07 / APPLICATIONS

Hodge 拉普拉斯的应用

1. 网络流量分析与优化

将交通/通信网络建模为单纯复形，边上的流量用 Hodge 分解拆分为：

  • 梯度分量：由拥堵差异驱动的流，可用势函数优化
  • 旋度分量：循环绕路导致的低效流量，需要移除
  • 调和分量：拓扑结构固有的绕行，无法通过局部调整消除
2. 协同过滤与推荐系统

在 item co-occurrence 单纯复形上，HodgeRank 方法利用 L₁ 的谱信息：

  • 用户偏好建模为边上的"比较流"
  • 不一致性 = 旋度分量的能量（curl energy）
  • 投影到梯度分量得到全局一致的排序
3. 拓扑数据分析 (TDA)

持续同调（Persistent Homology）用 Hodge 拉普拉斯加速：

  • 比标准持续同调算法快数个数量级
  • L₁ 的谱隙（最小非零特征值）反映洞的"稳定性"
  • 用于材料科学、神经科学中的形状分析
4. 图神经网络的推广

Simplicial Networks 将 GNN 推广到单纯复形：

  • 消息传递不仅沿边（0→1），还沿三角形（1→2）
  • 利用 B₁, B₂ 定义邻域卷积
  • 比图神经网络更好地捕捉高阶交互

import numpy as np
from scipy.linalg import eigh
from itertools import combinations

class SimplicialComplex:
    """
    单纯复形与 Hodge 拉普拉斯的完整实现

    一个单纯复形 K 由以下部分组成：
      - K_0: 0-单形集合（顶点）
      - K_1: 1-单形集合（有向边）
      - K_2: 2-单形集合（定向三角形）
    """

    def __init__(self, n_vertices, edges, triangles=None):
        """
        Args:
            n_vertices: 顶点数
            edges:      边的列表，每条边为 (i, j) 元组，表示有向边 i→j
            triangles:  三角形的列表，每个为 (i, j, k) 元组
                        定向：i→j→k→i（逆时针为正定向）
        """
        self.n_vertices = n_vertices
        self.edges = list(edges)
        self.triangles = list(triangles) if triangles else []

        # 构建关联矩阵
        self.B1 = self._build_B1()   # |V| × |E|
        self.B2 = self._build_B2()   # |E| × |T|

        # 构建 Hodge 拉普拉斯
        self.L0 = self._build_L0()   # 顶点拉普拉斯
        self.L1 = self._build_L1()   # 边拉普拉斯（核心）
        self.L2 = self._build_L2()   # 面拉普拉斯

    def _build_B1(self):
        """
        构建边界矩阵 B₁: 顶点 × 边

        B₁[v, e] =  +1  如果顶点 v 是边 e 的终点（箭头指向 v）
                    -1  如果顶点 v 是边 e 的起点（箭头离开 v）
                     0  如果不关联

        数学：∂₁[i→j] = [j] − [i]
        """
        nV, nE = self.n_vertices, len(self.edges)
        B1 = np.zeros((nV, nE))

        for e_idx, (i, j) in enumerate(self.edges):
            B1[i, e_idx] = -1   # i 是起点
            B1[j, e_idx] = +1   # j 是终点

        return B1

    def _build_B2(self):
        """
        构建边界矩阵 B₂: 边 × 三角形

        对于定向三角形 (i, j, k)，其边界为：
            ∂₂[i,j,k] = [j,k] − [i,k] + [i,j]

        即三条边：
            (j,k): 方向与定向一致 → +1
            (i,k): 方向与定向相反（应为 k→i，但存的是 i→k）→ -1
            (i,j): 方向与定向一致 → +1

        注意：如果边的有向存储与三角形定向不一致，符号会相应变化。
        """
        nE, nT = len(self.edges), len(self.triangles)
        B2 = np.zeros((nE, nT))

        # 建立边到索引的映射（同时记录方向）
        edge_to_idx = {}
        for idx, (i, j) in enumerate(self.edges):
            edge_to_idx[(i, j)] = (idx, +1)   # 存储方向：正向
            edge_to_idx[(j, i)] = (idx, -1)   # 反向

        for t_idx, (i, j, k) in enumerate(self.triangles):
            # 三角形定向边：(i,j), (j,k), (k,i)
            triangle_edges = [(i, j), (j, k), (k, i)]

            for te in triangle_edges:
                if te in edge_to_idx:
                    e_idx, sign = edge_to_idx[te]
                    # edge_to_idx 已包含方向匹配信息
                    # 如果 te = (i,j) 且库存也是 (i,j) → sign=+1（一致）
                    # 如果 te = (k,i) 但库存是 (i,k) → sign=-1（相反）
                    B2[e_idx, t_idx] = sign

        return B2

    def _build_L0(self):
        """
        0 阶 Hodge 拉普拉斯：L₀ = B₁B₁ᵀ

        这就是标准图拉普拉斯！
        L₀[i,i] = 节点 i 的度（出边+入边）
        L₀[i,j] = −1 如果 i 和 j 之间有边
        """
        return self.B1 @ self.B1.T

    def _build_L1(self):
        """
        1 阶 Hodge 拉普拉斯：L₁ = B₁ᵀB₁ + B₂B₂ᵀ

        这是 Hodge 理论的核心：
          - B₁ᵀB₁: "顶点梯度项"，衡量边上的散度
          - B₂B₂ᵀ: "三角形旋度项"，衡量边上的旋度

        两项之和使得 L₁ 同时编码了上下两个尺度的拓扑信息。
        """
        term1 = self.B1.T @ self.B1          # |E| × |E|
        term2 = self.B2 @ self.B2.T if self.B2.size > 0 else np.zeros((len(self.edges), len(self.edges)))
        return term1 + term2

    def _build_L2(self):
        """
        2 阶 Hodge 拉普拉斯：L₂ = B₂ᵀB₂
        """
        if self.B2.size == 0:
            return np.zeros((len(self.triangles), len(self.triangles)))
        return self.B2.T @ self.B2

    def spectrum(self, k):
        """
        计算 L_k 的特征值和特征向量

        Returns:
            eigenvalues: 升序排列的特征值
            eigenvectors: 对应的特征向量（列向量）
        """
        L = {0: self.L0, 1: self.L1, 2: self.L2}[k]
        if L.size == 0:
            return np.array([]), np.array([])
        vals, vecs = eigh(L)  # eigh 用于对称矩阵，更稳定
        return vals, vecs

    def betti_numbers(self, tol=1e-10):
        """
        计算 Betti 数：零特征值的重数

        β₀ = L₀ 的零特征值个数 = 连通分量数
        β₁ = L₁ 的零特征值个数 = 一维洞（环）数
        β₂ = L₂ 的零特征值个数 = 二维洞（空腔）数
        """
        betti = []
        for k in [0, 1, 2]:
            vals, _ = self.spectrum(k)
            beta = np.sum(np.abs(vals) < tol)
            betti.append(beta)
        return betti

    def hodge_decomposition(self, f):
        """
        对边上的信号 f 进行 Hodge 分解

        f = grad(φ) + curl(w) + h

        Args:
            f: 长度为 |E| 的向量，边上的流量/信号

        Returns:
            f_grad: 梯度分量（在 im(B₁ᵀ) 中）
            f_curl: 旋度分量（在 im(B₂) 中）
            f_harm: 调和分量（在 ker(L₁) 中）
        """
        f = np.array(f)

        # 1. 梯度分量：投影到 B₁ᵀ 的列空间
        # f_grad = B₁ᵀ(B₁B₁ᵀ)⁺B₁f，其中 ⁺ 表示伪逆
        B1 = self.B1
        B2 = self.B2

        # 投影到 im(B₁ᵀ)
        if B1.shape[0] > 0:
            L0_pinv = np.linalg.pinv(B1 @ B1.T)
            phi = L0_pinv @ B1 @ f        # 顶点势函数
            f_grad = B1.T @ phi            # 梯度流
        else:
            f_grad = np.zeros_like(f)

        # 2. 旋度分量：投影到 B₂ 的列空间
        if B2.size > 0 and B2.shape[1] > 0:
            L2_pinv = np.linalg.pinv(B2.T @ B2)
            w = L2_pinv @ B2.T @ f         # 面旋度势
            f_curl = B2 @ w                # 旋度流
        else:
            f_curl = np.zeros_like(f)

        # 3. 调和分量：正交补
        f_harm = f - f_grad - f_curl

        # 验证正交性（可选）
        # assert np.allclose(f_grad @ f_curl, 0)
        # assert np.allclose(f_grad @ f_harm, 0)
        # assert np.allclose(f_curl @ f_harm, 0)

        return f_grad, f_curl, f_harm

import numpy as np

def hodge_decomposition_dense(B1, B2, f, tol=1e-10):
    """
    对边上的信号 f 执行 Hodge 分解的纯 NumPy 实现

    原理：利用投影算子将 f 分解到三个正交子空间

      f = P_grad(f) + P_curl(f) + P_harm(f)

    其中：
      P_grad = B₁ᵀ(B₁B₁ᵀ)⁺B₁         投影到 im(B₁ᵀ)
      P_curl = B₂(B₂ᵀB₂)⁺B₂ᵀ         投影到 im(B₂)
      P_harm = I − P_grad − P_curl    投影到 ker(L₁)
    """
    f = np.asarray(f, dtype=float)
    n_edges = len(f)

    # ---- 梯度投影算子 ----
    L0 = B1 @ B1.T                    # 顶点拉普拉斯
    L0_pinv = np.linalg.pinv(L0)      # Moore-Penrose 伪逆
    P_grad = B1.T @ L0_pinv @ B1      # |E| × |E| 投影矩阵

    # ---- 旋度投影算子 ----
    if B2.size > 0 and B2.shape[1] > 0:
        L2t = B2.T @ B2               # B₂ᵀB₂
        L2t_pinv = np.linalg.pinv(L2t)
        P_curl = B2 @ L2t_pinv @ B2.T
    else:
        P_curl = np.zeros((n_edges, n_edges))

    # ---- 调和投影算子 ----
    I = np.eye(n_edges)
    P_harm = I - P_grad - P_curl

    # 执行投影
    f_grad = P_grad @ f
    f_curl = P_curl @ f
    f_harm = P_harm @ f

    # ---- 验证正交性 ----
    print("正交性验证（内积应接近 0）:")
    print(f"  ⟨grad, curl⟩ = {np.dot(f_grad, f_curl):.2e}")
    print(f"  ⟨grad, harm⟩ = {np.dot(f_grad, f_harm):.2e}")
    print(f"  ⟨curl, harm⟩ = {np.dot(f_curl, f_harm):.2e}")

    # ---- 能量分解 ----
    energy_total = np.dot(f, f)
    energy_grad = np.dot(f_grad, f_grad)
    energy_curl = np.dot(f_curl, f_curl)
    energy_harm = np.dot(f_harm, f_harm)

    print(f"\n能量分解:")
    print(f"  总能量:       {energy_total:.4f}")
    print(f"  梯度能量:     {energy_grad:.4f} ({100*energy_grad/energy_total:.1f}%)")
    print(f"  旋度能量:     {energy_curl:.4f} ({100*energy_curl/energy_total:.1f}%)")
    print(f"  调和能量:     {energy_harm:.4f} ({100*energy_harm/energy_total:.1f}%)")

    return f_grad, f_curl, f_harm


# 另一个视角：用特征向量分解

def hodge_decomposition_spectral(L1, f):
    """
    谱分解视角的 Hodge 分解

    对 L₁ 做特征值分解 L₁ = VΛVᵀ，
    零特征值对应的特征向量张成调和子空间，
    非零特征值对应的特征向量张成梯度+旋度子空间。
    """
    vals, vecs = np.linalg.eigh(L1)

    # 分离零特征值和非零特征值
    zero_mask = np.abs(vals) < 1e-10
    n_zero = np.sum(zero_mask)

    print(f"L₁ 零特征值个数: {n_zero} (= β₁)")

    # 调和分量 = 投影到零特征空间
    V_harm = vecs[:, zero_mask]       # |E| × β₁
    f_harm = V_harm @ V_harm.T @ f

    # 非调和分量
    f_nonharm = f - f_harm

    # 进一步拆分梯度/旋度需要 B₁ 和 B₂ 的信息
    # 这里只展示谱分解与拓扑的直接联系

    return f_harm, f_nonharm

def visualize_simplicial_complex(vertices, edges, triangles=None,
                                  edge_flow=None, title="Simplicial Complex"):
    """
    可视化单纯复形，可选显示边上的流量

    Args:
        vertices:    [[x0,y0], [x1,y1], ...] 顶点坐标
        edges:       [(i,j), ...] 有向边
        triangles:   [(i,j,k), ...] 定向三角形
        edge_flow:   长度为 |E| 的向量，边上的流量值（用于着色）
    """
    fig, ax = plt.subplots(1, 1, figsize=(8, 8))

    # 绘制三角形填充
    if triangles:
        for t in triangles:
            pts = np.array([vertices[i] for i in t])
            poly = Polygon(pts, alpha=0.2, facecolor='blue',
                          edgecolor='none')
            ax.add_patch(poly)

    # 绘制边
    segments = []
    colors = []
    for idx, (i, j) in enumerate(edges):
        segments.append([vertices[i], vertices[j]])
        if edge_flow is not None:
            # 流量大小映射到颜色
            val = edge_flow[idx]
            colors.append(plt.cm.RdBu_r(0.5 + 0.5 * np.sign(val) *
                          min(abs(val) / 2.0, 1.0)))
        else:
            colors.append('gray')

    lc = LineCollection(segments, colors=colors, linewidths=2)
    ax.add_collection(lc)

    # 绘制顶点
    xs, ys = zip(*vertices)
    ax.scatter(xs, ys, c='white', s=200, zorder=5, edgecolors='black')
    for i, (x, y) in enumerate(vertices):
        ax.text(x, y, str(i), ha='center', va='center',
               fontsize=12, fontweight='bold')

    ax.set_aspect('equal')
    ax.set_title(title)
    ax.axis('off')
    plt.tight_layout()
    plt.show()

09 / FAQ

常见问题

为什么 L₁ 比 L₀ 更重要？
L₁ 是边拉普拉斯，它同时捕捉了两种拓扑信息：B₁ᵀB₁ 衡量边在顶点层面的"散度"（哪些边上的流汇聚或发散），B₂B₂ᵀ 衡量边在三角形层面的"旋度"（哪些边参与局部循环）。许多实际数据（如交通流、推荐系统中的成对比较）天然定义在边上而非顶点上，因此 L₁ 比 L₀ 更有建模能力。此外，L₁ 的零空间维数 β₁ 直接反映了一维洞的数量，这是标准图拉普拉斯无法提供的。
定向（Orientation）有什么影响？
定向决定了关联矩阵中元素的正负号，进而影响特征向量的方向。然而，特征值本身与定向无关。这意味着 Betti 数、谱隙等拓扑不变量不依赖于你如何给边和三角形定向。实际计算中，只需选择一个一致的定向规则（如边的字典序定向、三角形的逆时针定向）即可。
Hodge 拉普拉斯和持续同调（Persistent Homology）有什么关系？
两者都计算 Betti 数，但方法不同。持续同调通过不断增大连接阈值，追踪洞的"诞生"和"死亡"时间，得到持久性条形码。Hodge 拉普拉斯则直接对固定复形做谱分析，零特征值个数等于 Betti 数。近年来有研究将两者结合："持续谱"（Persistent Spectra）通过追踪特征值随阈值的变化来得到更丰富的拓扑信息。Hodge 拉普拉斯的优势是计算更快（矩阵分解而非条码计算），但持续同调能捕捉多尺度的拓扑演化。
如何从高维数据（如点云）构建单纯复形？
最常用的方法是Vietoris-Rips 复形：给定点云和距离阈值 ε，当 k+1 个点两两距离都小于 ε 时，它们构成一个 k-单形。通过从小到大调整 ε，可以得到一个复形序列（filtration）。另一个常用方法是Čech 复形，要求 k+1 个点有公共交集。VR 复形更容易计算（只需要检查成对距离），而 Čech 复形有更好的理论保证（Nerve 定理）。在 TDA 中，通常先计算 VR 复形，再对其做持续同调或谱分析。

参考: Hodge (1941), Eckmann (1944), Horak & Jost (2013), Lim (2020)
